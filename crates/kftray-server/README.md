# kftray-server

kftray-server is the in-cluster relay used by kftray and kftui for proxy forwarding, UDP traffic and reverse tunnels.

- [Relay server guide](https://kftray.app/docs/resources/relay-server): modes, environment variables and Docker commands.
- [Architecture](https://kftray.app/docs/resources/architecture): traffic paths and shared components.
- [Security](https://kftray.app/docs/resources/security): release verification and vulnerability reporting.
