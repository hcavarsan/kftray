# kftui

kftui manages Kubernetes port forwards from the terminal. It shares configurations and a Rust backend with the kftray desktop app.

- [Install kftui](https://kftray.app/docs/getting-started/installation).
- [Terminal guide](https://kftray.app/docs/interfaces/terminal): navigation and keyboard shortcuts.
- [CLI guide](https://kftray.app/docs/interfaces/cli): imports, scripts and headless use.
- [Configuration](https://kftray.app/docs/configuration): fields, workload types and storage.
- [Build from source](https://kftray.app/docs/resources/building-from-source#terminal-app).

Source code and releases are in [hcavarsan/kftray](https://github.com/hcavarsan/kftray).
